# ⚖ 규정 제·개정 에이전트

**모든 직원이 따르는 규정의 품질과 상위법 정합성을 관리하는 웹 서비스**입니다.
기관의 내규(사규)·지자체의 자치법규·중앙부처의 행정규칙은 조직 구성원 전체의 권리·의무와 일하는 방식을 정하지만, 이를 다듬는 규정 담당자는 기관마다 한두 명입니다. 이 서비스는 그 담당자가 **규정 전체를 한눈에 진단**(없는 조 인용, 바뀐 명칭, 상위법 개정 미반영, 수치 불일치)하고, **한 문장 지시로 개정안·신구조문대비표·이유서·심의 문서까지** 만들며, 만든 개정문이 맞는지 **스스로 검증**하도록 돕습니다.

**누가 혜택을 보나**
- 규정 담당자: 개정 실무(초안·대비표·개정문·공고문·심의 자료)와 전체 규정 정비가 사람 한 명의 기억에서 도구로 옮겨 갑니다.
- 모든 직원: 자기에게 적용되는 규정이 상위법과 어긋나거나 서로 충돌하는 일이 줄고, “내규 자문”으로 근거 조문을 바로 찾습니다.
- 감사·심의 위원: 심의 사전검토·인용 영향·수치 불일치 결과를 근거로 받아 봅니다.
- 국민·거래 상대: 공개되는 규정(알리오 공시, 자치법규 공포)의 정확성이 올라갑니다.

- 기본 설정은 한국농업기술진흥원(KOAT)의 내규 126건입니다. 기관 프로필(`org_config.json`)과 규정 원문만 바꾸면 **다른 공공기관·지자체·중앙부처**에서도 씁니다(아래 「지자체·중앙부처에서 쓰기」).
- 브라우저만 있으면 됩니다(PC·휴대폰).

## 주요 기능

| 화면 | 하는 일 |
|---|---|
| ✦ 에이전트 | 한 문장 지시(“여비규정 제15조 일비를 3만원으로”) → 대상 찾기·초안·영향 분석·점검·문서까지 자동 수행 |
| 🩺 건강검진 | **진단 요약**(전체 내규 점수·등급, 정비 우선순위, 상위법·행정규칙(훈령·고시 등) 개정 미반영 — 법제처에서 못 찾은 이름은 따로 표시, 곧 시행되는 상위법, 중복 등록 의심, 별표·서식의 옛 기관명·직위) · **오류 목록**(인용·명칭·조 번호 오류를 내규별로, 같은 문장인데 수치만 다른 곳) · **내규 하나 점검**(항·호 순서·표기·부칙·별표 인용까지). 조문을 읽지 못한 내규는 점수 대신 “읽지 못함”으로 표시 |
| 💬 내규 자문 | 직원 질의에 근거 조문을 찾아 회신서 작성(AI 인용은 원문과 대조해 표시), 같은 쟁점의 법제처 법령해석례 참고 |
| 📖 용어 사전 | 내규의 정의 조항·약칭 모음(규정 온톨로지 1단계). 같은 용어를 내규마다 다르게 정의하면 ‘정의 불일치’로 표시하고 조문 점검·자문이 알림, 일상어↔내규 용어 동의어 추가, SKOS(JSON-LD) 내보내기 |
| 🏢 조직·권한 | 직제 조문으로 만든 조직도(본부·실·팀·센터와 분장 업무), 위원회 설치 조문에서 뽑은 구성 인원·위원장·간사·심의 사항(규정 온톨로지 2단계), 직위·기능 부서가 나온 조문, 직제에 없는 옛 조직명 찾기 → 일괄 정비. **권한·절차**(3단계): 조문 문장의 누가·무엇을(승인·보고·심의 …)·누구에게·언제(기한)·의무/재량/금지와 위임전결 별표의 전결권자 — 내규 자문이 “누가 결재하나요?”에 전결권자를 함께 답함 |
| 🆕 제정 · ✏️ 개정 | **단계에 들어서면 그 단계 일을 먼저 해 둠**(사용자는 확인하고 고친다): 제정은 내규명을 적으면 다른 기관(알리오) 같은 종류 규정을 찾아 관련 조문을 미리 담고, “초안까지 한 번에”로 여러 기관이 공통으로 둔 조(예: 운영책임자·비행 승인·사고 보고)를 넣은 초안과 **조문별 참고 출처**를 만들며(AI 키가 없어도), 점검 단계는 자동 실행. 개정은 고른 조문을 고치기 칸에 자동으로 담고(AI 키와 개정 의도가 있으면 AI 수정안), 확인·검토에 들어서면 모두 점검. **지시문의 수치는 AI 없이도 반영**(“일비를 3만원으로” → 별표 2 표의 “일 비” 열만 25,000 → 30,000, 식비 열은 그대로 — 표의 머리 줄과 행의 칸 수가 맞을 때만 바꾸고 아니면 손대지 않음). 고치기 화면은 수정안이 생기면 시행일·참고 자료·도구를 “세부 설정·도구”로, 개정 이유·부칙을 접어 두고(비우면 자동 작성), 그대로인 조문 카드는 한 줄로 접음. 조문 초안·수정안, **조 번호 도구**(조 이동·맞교환·빈 번호 메우기 — 같은 규정 안의 인용은 자동 정정, 개정문은 “제9조를 제8조로 한다.”), 확인·검토 한 줄 요약(“모두 점검하기” 한 번으로 대비표·영향·점검·같은 문장·개정문 검증·사전검토), **개정문 검증**(만든 개정문을 현행에 되돌려 적용해 수정안과 같은지 확인), 별표·서식 수정(금액표·결재 서식도 조문처럼 골라 고치고 개정문·대비표에 반영, 고친 조문의 관련 별표는 자동으로 담음), 유관 기관 수치 비교(알리오), 신구조문대비표, 인용 영향 분석, 같은 문장이 있는 다른 곳(함께 고칠 곳), 심의 사전검토, 심의 제출 패키지(.hwpx·.docx) |
| 🧩 일괄 정비 | 바뀐 기관명·직위·내규명을 모든 내규에서 조사까지 맞춰 바꾸고 개정문·부칙 작성 |
| 🏛 상위법 영향 | 법령 개정에 영향받는 내규 조문 찾기(약칭 “법 제N조”·“같은 법”까지). **법령 조문 지도**(규정 온톨로지 4단계): 내규가 인용한 법령의 조 단위 연결 — 법령 → 조 → 그 조를 인용한 내규 조문, 법제처 현행 조문과 대조(없어진·삭제된 조 표시), 조를 눌러 바로 영향 분석 |
| 📚 내규 목록 | 내규 찾기·조문 보기, 조문 연혁(업로드된 판마다 바뀐 내용 비교) |
| 🕸 인용 관계 | 내규 사이 인용 관계·파급 범위 |
| 🗂 절차 안내 | 기관 절차에 맞춘 단계·일정·추진계획표 |
| 🧾 작업 실적 | 저장한 산출물의 AI 활용·사람 검토 기록(기관 전체 월별 실적은 켤 때만) |

다른 공공기관 사규(알리오)를 찾아 초안 참고로 쓸 수 있습니다.

## 화면 구성

왼쪽 메뉴는 세 묶음입니다. 처음 쓰는 사람은 **작업**(에이전트·건강검진·개정·제정)만 보면 되고, **찾아보기**(내규 목록·자문·용어 사전·조직·권한)와 **정비 도구**(일괄 정비·상위법 영향·인용 관계), **관리**(절차 안내·작업 실적)는 접혀 있다가 누르면 펼쳐집니다. 옛 “전체 점검”은 건강검진의 “오류 목록·내규 하나 점검” 보기로 들어갔습니다.

## AI는 초안, 확인은 사람

- AI가 쓴 조문은 “AI 원문 그대로 / 사람이 고침”으로 표시합니다.
- 심의 제출 전에 검토자가 “AI 작성 조문 검토 확인”을 해야 합니다. 확인 뒤 조문을 고치면 다시 확인합니다.
- 저장 문서 끝에 작성 지원·검토자를 표기하고, 저장할 때마다 작업 실적에 남깁니다.
- AI 키가 없으면 규칙 기반으로 동작합니다. AI 결과는 반드시 원문과 대조해 검토하세요.

## AI 전송 범위와 선택

- AI를 켜면 **개정 의도·질의와 대상 조문 본문**이 고른 AI 제공자(Gemini·Claude·GPT) 서버로 전송됩니다. 등록된 현행 내규는 「공공기관의 운영에 관한 법률」에 따라 알리오에 공시되는 **공개 정보**라 전송 자체는 보안 쟁점이 아닙니다.
- 주의할 것은 **공개 전 개정안**(심의·의결 전의 보수·인사·직제 개정안 등)입니다. 기관 보안지침에 따라 ① 기관 LLM(Ollama, `OLLAMA_BASE_URL`)이나 행정안전부 AI 공통기반(OpenAI 호환) ② AI 없이 규칙 기반 작업 중에서 고르세요. 개정문·대비표·점검·검진·문서 세트는 AI 없이 모두 동작합니다.
- AI 키는 서버에 저장하지 않습니다(브라우저 세션에만, 요청마다 전달). 사내망 배포는 **선택 구성**입니다: `python run_local.py`로 내부 서버에 띄우면 외부로 나가는 것은 사용자가 켠 AI·법제처·알리오 조회뿐입니다.
- 화면의 [AI 설정]에 같은 안내를 두었습니다.

## 검증 결과(2026. 10., 등록 내규 126건 기준)

- **건강검진**: 보고된 문제 16건(없는 조 인용, 다른 내규의 삭제된 조 인용, 바뀐 내규명 7건, 옛 명칭, 조 번호 중복, 중복 등록)을 원문과 대조해 **16건 모두 실제 결함**. 일부러 심은 오류 10종 중 8종 탐지(나머지 2종은 이후 보강: 별표·서식의 옛 명칭, 조문을 읽지 못한 내규 표시).
- **지시문 해석**(규칙 기반, AI 없음): 30건 중 모드 30/30, 대상 내규 19/19, 대상 조문 14/15.
- **개정문 왕복 검증**: 내규 126건에 무작위 개정(글자 바꾸기·단서·항 신설·끼워 넣기·삭제·조 신설 등)을 가해 개정문을 만들고 그 개정문을 현행에 되돌려 적용하면 수정안과 일치 — 6개 시드 **1,279건 중 1,279건(100%)**. `python scripts/roundtrip_amend.py`로 재현하며, 테스트(`tests/test_verify_fixes.py`)에 포함. 화면의 “확인·검토 → 개정문 검증”이 같은 함수로 매 개정안을 검증합니다.
- **끝까지 실행**: “여비규정 제15조의 일비를 3만원으로” 한 문장 → 제15조·관련 별표 2·4 자동 연결 → 별표 숫자 수정 → 영향분석·점검·사전검토·개정문 검증 → 개정문·대비표·한글 저장까지 사람이 하는 일은 표의 숫자 두 곳과 제안 부서 입력뿐.

## 개인정보

- 작성 중인 내용은 사용 중인 브라우저에만 저장됩니다(작업 백업·복원 가능).
- AI 키는 탭을 닫으면 지워집니다.
- 작업 실적은 기본으로 브라우저에만 남습니다. 기관 전체 대장은 꺼져 있고, 관리자가 `LEDGER_ENABLED=1`로 켜면 저장 시각, 산출물 종류·형식(hwpx·docx), 대상 내규명, AI 모델명, AI 작성분 수·담당자 수정 수, AI 인용 수·원문 일치 수, 검토 확인 여부를 서버에 보냅니다. 본문·질의·검토자 이름은 보내지 않습니다.

### 환경변수(모두 선택)

| 이름 | 용도 |
|---|---|
| `GEMINI_API_KEY` 등 | 서버 공용 AI 키(사용자 키가 우선) |
| `LAW_OC` | 법제처 Open API ID |
| `REG_UPLOAD_TOKEN` | 내규 등록 암호 |
| `GITHUB_TOKEN`, `GITHUB_REPO` | 읽기 전용 배포에서 내규 등록·작업 실적을 저장소에 커밋 |
| `LEDGER_ENABLED` | `1`이면 작업 실적 기관 대장을 켬(기본 꺼짐) |
| `LEDGER_DIR`, `LEDGER_BRANCH` | 기관 대장 위치(기본 `ledger/`, 읽기 전용 배포는 브랜치 `ledger-data`) |
| `ORG_CONFIG`, `REG_DIR`, `REG_MANIFEST` | 기관별 프로필·내규 원문 위치 |

전체 목록은 `.env.example`을 보세요.

### 지자체·중앙부처에서 쓰기(자치법규·행정규칙)

규정을 읽고(조·항·호·목, 부칙, 별표·서식), 개정문과 신구조문대비표를 만들고, 인용·명칭·번호를 점검하고, 상위법을 법제처에서 대조하는 엔진은 **문서 종류를 가리지 않습니다**. 조례·규칙·훈령·예규·고시도 같은 틀로 다룹니다.

- **바로 해 보기(설치 없이)**: 개정 화면의 **원문 붙여넣기**에 조례 전문을 붙여 넣으면 개정안·개정문(“○○ 조례 일부개정조례안”)·대비표·점검·개정문 검증이 그대로 동작합니다. 부칙 기본 문구도 “이 조례는 공포한 날부터 시행한다.”로 바뀝니다.
- **기관 전체로 쓰기**: 가상의 ‘가온군’ 예시 프로필과 자치법규 2건을 `samples/local_gov/`에 두었습니다.
  ```bash
  export ORG_CONFIG=samples/local_gov/org_config.json REG_DIR=samples/local_gov/regulations REG_MANIFEST=samples/local_gov/regulations_manifest.json
  python scripts/import_regulations.py samples/local_gov/regs --reset   # 조례·시행규칙 등록
  python run_local.py                                                   # 군수·자치법규·입법예고 기준으로 동작
  ```
  건강검진은 조례가 인용한 「농업기계화 촉진법」·「지방자치법」을, 인용 영향은 조례 ↔ 시행규칙 관계와 별표 1을 찾습니다(테스트 `tests/test_local_gov.py`).
- **다른 점만 바꾸면 됩니다**: 기관장·규정 낱말(`reg_word`: 내규 → 자치법규), 심의기준(`review_criteria`: 상위 법령 정합성·입법예고), 절차(`procedure`). 알리오 비교는 공공기관 전용이므로 지자체에서는 비워 둡니다.

### 다른 기관에서 쓰기
1. `org_config.json`을 복사해 기관명·직위·절차·심의기준을 고칩니다.
2. `python scripts/import_regulations.py <폴더> --reset`으로 내규 원문을 넣습니다.
3. (선택) `python scripts/build_embeddings.py`로 의미 검색 색인을 만듭니다.
